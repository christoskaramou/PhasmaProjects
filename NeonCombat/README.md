# NEON COMBAT — a modern remake of Atari 2600 *Combat* (PhasmaEngine)

Two neon tanks duel across maze arenas. Precise procedural geometry (chamfered hull, glacis,
hex turret, muzzle brake, road wheels, track cleats, bevelled wall blocks with glowing seams, tiled
floor) is generated by `tools/gen_meshes.py` and cooked to `.pemesh` with **PhasmaCook**.
VFX: muzzle flash (emissive flash + cone + light + sparks + smoke), glowing tracer shells with
ribbon trails, sparks and a point light, ricochet sparks, fireball explosions with shock rings, tumbling
debris that bounces off walls, scorch marks, smoke, track dust, exhaust, ambient motes, dynamic
point lights (tank underglow, shells, flashes, arena corners), bloom, tonemapping, colour grading, TAA,
screen shake and a hit flash.

## Run
* Windows: `run.cmd` (or `powershell -File run.ps1 [-Api vulkan|d3d12]`). It uses a private runtime copy of
  PhasmaPlayer from `..\..\PhasmaEngine\build*\Release` under `%LOCALAPPDATA%\PhasmaGames\NeonCombat`.
* Linux box: `/workspace/games/combat/run.sh` (Xvfb + lavapipe), `restart.sh` / `stop.sh` (own PID only), MCP on :9106.

## Controls
| | Player 1 (GREEN) | Player 2 (MAGENTA) |
|---|---|---|
| Turn | A / D | Left / Right |
| Drive forward | Space (W also) | Up |
| Reverse | S | Down |
| Fire | Left mouse click (or F, Left Shift) | Enter / Right Ctrl / Right Shift / Keypad 0 |

In 1-player mode the arrow keys and Enter also drive Player 1, and Player 2 is the AI.
Menus: Up/Down select, Left/Right change, Enter confirm. Esc or P pauses (Resume, Restart, Settings, Quit to title). M mutes.

## Rules
One shell per tank in flight (as in the original). A hit scores a point and blasts the target into a spin.
First to the target score (3/5/10/15) wins. Options on the title screen: arena (Classic, Labyrinth, Pillars),
bouncing shots (ricochet up to 4 times) on or off, score to win, AI skill (Rookie, Veteran, Ace). The AI
uses a BFS distance field to hunt you through the maze, checks line of sight, and plans bank shots when ricochet is on.

## Settings
Shared settings menu (`Assets/Scripts/Lib/settings_menu.lua`): master volume (50% by default), SFX, mute, graphics
quality, bloom, AO, particles, screen shake and an FPS badge. Saved to `Assets/Save/settings.cfg`.

## Rebuild assets
`python3 tools/gen_meshes.py` (meshes, arenas.lua and main.pescene; cooks with PhasmaCook), `python3 tools/gen_assets.py` (sky HDR and WAV sfx).
