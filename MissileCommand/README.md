# Missile Command - Neon Night (Phasma Engine)
Run: run.ps1 / run.cmd (opens the project in PhasmaPlayer).
Controls: mouse aim; Left click/Space = fire nearest base; A/S/D or 1/2/3 = fire specific base; right click = centre base;
P or the "II PAUSE" button = pause; O/Tab = settings; Esc = title; Enter = start. All menu items are mouse-clickable.
Features: cooked skyscraper cities (window grids, antennas, domes, beacons, street lights, glass), rocky burning meteors with fire/smoke/ember trails,
missiles with exhaust+smoke, fireballs, sparks, debris, shockwave dust, burning rubble, TAA + soft bloom.
